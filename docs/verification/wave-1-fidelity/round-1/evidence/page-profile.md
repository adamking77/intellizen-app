# Page and content profile

## Shell

Three persistent regions: workspace navigation, route content, agent panel.
Connected and segmented pane preferences both render. The native Home capture
shows real widgets and engine state. The installed D.13 fixture contributes
`Plugin proof`; the deliberately broken fixture fails in its own sidebar row.

## Agents

Primary actions are New agent and New team. Cards are grouped under Agents and
Teams. The editor contains avatar, role, engine/provider, model, voice, identity,
and context. The team sheet selects two to six agents and names the team. The
current browser fixture cannot populate native profiles or teams, so only the
empty page and editor anatomy are current rendered evidence.

## Settings

Six sections: Providers, Capabilities, Context, Voice, Appearance, General.
The current implementation preserves the donor two-column Settings shell,
selection treatment, compact rows, muted help copy, and token palette. Provider
copy and controls intentionally reflect the Fable 5.1 architecture: Hermes is
the persistent engine and ACP agents start on demand. General likewise omits the
donor's multi-provider connect/disconnect policy rows. Those are product changes,
not visual substitutions.

## Agent panel and floating modes

The docked panel includes the target picker, transcript, run status, decisions,
message actions, composer, dictation, conversation, and eject action. The
standalone window includes a reduce-to-HUD action and redock action. The HUD has
a fixed-height bar and an upward-opening chat surface. A live transcript and a
fresh native HUD screenshot were not available in this round.
