## 1. What this is

The app you have, with one design system applied everywhere. Three planes, fixed Places, the hierarchy tree, the agent panel and its four modes, the Database editor with all its views, the workflow library and composer, the agent cards and editor all stay. What changes is the frame around them, the type, the language, and what is on screen at rest.

The user is neurodivergent. Rules from the ND OS matrix and the Sogo ethos are not a layer on top; they are in the component contracts below. If a rule and a visual conflict, the rule wins.

## 2. Non-negotiable rules

These apply to every surface and every future component. Add them to `DESIGN.md` as a section.

1. **No timers.** Never render elapsed time, countdowns, "waiting 52m", or escalation deadlines. A question shows the time it was asked, as a fact.
2. **No blocking language.** Never "waits on you", "blocked", "nothing can move until". Use "a question for you". State what agents are doing meanwhile.
3. **Actions are invitations in equal weight.** No accent-filled primary buttons on decisions. Choices render as text with a hairline underline; one may carry "· recommended" in mono.
4. **Done signals.** Every move, task and output carries a "done when" line.
5. **Session mode.** A session opens by asking what is available: Thinking, Deciding, Executing, Not today. The mode is stored locally, shown in the dock pill, and shapes Home. Not today suppresses notifications, HUD and toasts; agents are unaffected; it clears on the next session start only.
6. **Counts, never percentages, for anything about the user.** No streaks, completion rates, daily minimums, reminders or praise. Run outcomes stay as counts of runs.
7. **No coloured left borders anywhere.** No accent rails, no border-left markers. Emphasis comes from the eyebrow colour, type weight and a tinted plane.
8. **One opaque surface for everything that floats.** Popovers, hover cards, decisions, margin notes, record peeks, step fields, modals: same background, border, radius.
9. **Data stays where it is.** Vault markdown, workspace records, Hermes profiles. Nothing is copied into a new store to render these screens. Agents write only through proposals and confirmed MCP writes.
10. **Cards for inventories, lists for activity and long sets.** Workflows and Agents keep card grids as their default view with a list alternative. Skills, tools, MCPs, plugins, receipts and signals are lists.

## 5. Surfaces

Each entry: frame, what changes, which components, data, acceptance.

### 5.1 Home (8a, 8b, 8c, 8d, 8e)

Home has four modes. `src/views/Home.tsx` gains a mode switch above the existing pinned grid; the grid is unchanged and reachable with ⌘. in any mode.

- **New session (8a):** first open of a session shows the question "What is actually available today?" with four rows. Remembers yesterday's answer. Silence opens Thinking. Meanwhile paragraph from the activity snapshot and pending decisions.
- **Thinking (8b):** eyebrow, one sentence, one sub paragraph, the first pending question as Choices, the pulse. Sentence composed from: pending decisions in the panel store, live sessions, `workspace.work_events` since last visit, Workflow Runs. Numbers appear on hover of the sentence.
- **Deciding (8c):** one pending decision at a time, full width. Sources, meanwhile, if-you-leave-it lines. Choices with recommended. Answering calls the same approve or clarify action as the panel. Esc returns.
- **Executing (8d):** the move menu. Reads Tasks records that carry `trigger`, `done_when`, `effort` fields (new fields on the Tasks database, additive). Groups by trigger, never by date. Shows the workspace's not-doing list (a Tasks or Biz Ops record with kind `keeping_out`). Set this project aside in the dock.
- **Not today (8e):** the ambient screen. Suppresses toasts, HUD and notifications. Agents unaffected.

Acceptance: no clock anywhere; the mode survives reload and clears on the next session start; ⌘. shows the existing dashboard unchanged.

## 6. Language

Second person, calm, invitation. Allowed: "you may", "when you want it", "it keeps". Banned in UI copy: should, need to, make sure, waiting on you, blocked, overdue, streak, reminder, exclamation marks, em-dashes. Agent state words: reading, drawing, checking, resting, on demand. Questions are "a question for you". Rest is "resting", never idle or inactive.

## 7. Trace avatar

Third `avatarStyle: "trace"` beside blob and sphere in `src/components/agents/avatar.tsx` and `agent-model.ts`. Random, not DNA-shaped: the generator should produce varied line figures, not only helices.

- Profile fields: `avatarStyle`, `avatarSeed` (integer), `avatarColor` (existing). Preserve `avatarKind` as the existing blob silhouette.
- Generator: seeded PRNG (mulberry32 or equivalent). From the seed derive: strand count 1 to 3, per-strand amplitude, wavelength, phase, drift, stroke weight, opacity, and a figure type from {sine, loop, arc, knot, dotted}. Render as one SVG in a 40×40 viewBox, stroke only, the agent colour, no fill.
- Same seed always renders the same figure. "Generate another" picks a new seed and previews; Save writes it to the profile.
- Sizes: 22 (lists), 26 (team sheet), 44 (cards), 56 (editor). Ring optional at 44 and above.
- Reference implementation of the sine family: `trace_avatar()` in `design/explorations/claude-design-2026-09-06/build_turn8.py`.

## 8. Data and back-end mechanics

Sentences reuse the current Activity sources, `workspace.work_events`, source-specific pending decisions, `workspace.records`, `record_revisions` and Workflow Runs. Tasks receives the five additive metadata fields specified above through the canonical MCP server, preserving existing definitions and records. The approval-step `meanwhile` field requires durable independent-step continuation in the existing runner; `reminder` defaults to never. Session mode uses native process-lifetime identity plus local preferences; trace style and seed round-trip through profile and ACP adapters. `pin_view_to_home` retains its existing persistence path.
