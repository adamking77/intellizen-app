# Product

## Register

product

## Users

IntelliZen is a single-user macOS operating surface for Adam King and the
GenZen agent team. Adam uses it to move between company records, intelligence,
documents, investigations, workflows, and agent conversations without copying
context between tools or losing the receipt trail. Agent-facing surfaces must
also make delegated authority, runtime identity, evidence, and human approval
boundaries legible.

## Product Purpose

IntelliZen turns GenZen's live workspace data and local or durable agent
runtimes into one inspectable operating system. It should make it fast to find
the right record, direct work through a role, follow execution, review evidence,
and make the decisions that remain human-only. Success means the application
feels calmer than the underlying system while preserving exact provenance,
failure states, and approval requirements.

## Brand Personality

Precise, calm, editorial. The interface should communicate expert confidence
without spectacle: dense when the work demands it, quiet in its chrome, and
plainspoken about what is running, blocked, verified, or unknown.

## Anti-references

- Generic SaaS dashboards built from interchangeable cards and oversized
  metrics.
- Cockpit costume, decorative HUD chrome, scanlines, glows, and kinetic status
  effects.
- "AI feature" styling such as purple gradients, sparkle icons, agent bubbles,
  or separate automation dashboards inside chat.
- Consumer chat interfaces that hide identity, runtime, authority, receipts, or
  canonical records.
- Interfaces that make failure resemble emptiness or imply progress with an
  unexplained spinner.

## Design Principles

1. Make truth easier to see than optimism: failure, ambiguity, authority, and
   verification must remain distinct.
2. Keep the operator in one coherent workspace: conversation events should
   connect to canonical records instead of becoming a second task system.
3. Let data and provenance carry the visual weight; keep chrome subordinate.
4. Preserve familiar product interaction patterns so attention stays on the
   decision or work, not the interface.
5. Give every gesture one meaning and every consequential action an explicit,
   inspectable acknowledgement.

## Accessibility & Inclusion

The current product target is a single known macOS user rather than a formal
public WCAG conformance claim. Keyboard parity, visible focus, Escape and focus
return for overlays, reduced nonessential motion, semantic status text in
addition to color, and usable 390px panel width are required. Loading, empty,
and error states must remain visually and verbally distinct.
